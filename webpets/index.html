🐾 WebPet

A roaming pixel pet on your page. Hover it. Try the examples below.

Data-attribute (auto-init)

<script
  src="/webpet.js"
  data-animal="fox"
  data-color="red"
  data-hover-message="hi!"
></script>

Programmatic

<script src="/webpet.js"></script>
<script>
  new WebPet({
    animal: 'dog',
    color:  'black',
    scale:  0.6,
    hoverMessage: 'woof!',
  });
</script>

Mouse follower

new WebPet({
  animal: 'zappy',
  followMouse: true,
  scale: 0.6,
});

Multiple pets

new WebPet({ animal: 'snail' });
new WebPet({ animal: 'crab',
             hoverMessage:'pinch!' });

Horse (paint variant)

new WebPet({
  animal:   'horse',
  color:    'paint',
  subcolor: 'beige',
});

All options

new WebPet({
  animal:       'fox',
  color:        'red',
  scale:        0.5,      // render scale
  speed:        5.2,      // px / frame
  followMouse:  false,
  hoverDist:    50,       // px
  hoverAction:  'swipe',
  hoverMessage: 'hi!',
  position:     'fixed',  // or 'absolute'
  zIndex:       9999,
  // override media path:
  mediaBase: '/media',
});
